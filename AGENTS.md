# AGENTS.md

This is the agent entry point for the `rundeck-plugins` organization.

The canonical, full guidance lives in [`CLAUDE.md`](CLAUDE.md) in this repo. Read it and follow it.

Quick map:
- Working agreements, decision authority, build/release and branch conventions: [`CLAUDE.md`](CLAUDE.md)
- Per-plugin inventory, types, and gotchas: [`PLUGINS_OVERVIEW.md`](PLUGINS_OVERVIEW.md)
- Per-repo Copilot instructions are generated from [`templates/copilot-instructions.shared.md`](templates/copilot-instructions.shared.md)

`CLAUDE.md` and `AGENTS.md` are kept in sync; if they ever diverge, `CLAUDE.md` wins.
